১ সার্ভারে ঢুকুন (SSH)

ssh root@SERVER-IP

ইউজার root না হলে ubuntu বা আপনার ইউজারনেম দিন। পাসওয়ার্ড চাইলে দিন (লেখার সময় স্ক্রিনে কিছু দেখাবে না, এটাই স্বাভাবিক)।

২ এক কমান্ডে ইনস্টল

সার্ভারে ঢোকার পর শুধু এই একটা কমান্ড কপি করে পেস্ট করুন আর Enter দিন:

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo bash

৫ থেকে ১০ মিনিট লাগবে। শেষে এরকম দেখাবে:

এরপর এটা চালিয়ে দেখুন সব ঠিক আছে কিনা। সব লাইনে ✔ দেখালে কাজ শেষ:

sudo aria2-panel status

নিজের পছন্দমতো সেটিং দিয়ে ইনস্টল (ঐচ্ছিক)

সেটিংকাজডিফল্ট
PANEL_PASSWORD=...admin-এর পাসওয়ার্ড নিজে ঠিক করানিজে থেকে তৈরি হয়
DOWNLOAD_DIR=...ফাইল কোন ফোল্ডারে থাকবে/srv/downloads
TUNNEL=1ডোমেইন ছাড়াই ফ্রি HTTPS লিংক (বিস্তারিত)বন্ধ

উদাহরণ:

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo PANEL_PASSWORD='MyStrongPass123' DOWNLOAD_DIR=/data bash
ইনস্টল স্ক্রিপ্ট আসলে কী কী করে?
  1. aria2, nginx, Python, rclone, yt-dlp, ffmpeg, 7-Zip ইনস্টল করে
  2. aria2 নামে আলাদা একটা ইউজার বানায় (নিরাপত্তার জন্য)
  3. aria2 কনফিগার করে: ১৬ কানেকশন, রিস্টার্টের পরেও ডাউনলোড চালু থাকা, টরেন্টের জন্য ভালো tracker
  4. ওয়েব প্যানেল বসায় আর nginx দিয়ে পোর্ট 80-তে চালু করে
  5. RAM ২ GB-র কম হলে ২ GB swap বানায়, আর নিজে থেকে সিকিউরিটি আপডেট চালু করে
  6. প্রতি সপ্তাহে tracker তালিকা আর yt-dlp আপডেট করার ব্যবস্থা করে
  7. aria2-panel কমান্ড বসায়, আর ufw ফায়ারওয়ালে দরকারি পোর্টের নিয়ম যোগ করে

৩ ক্লাউড প্যানেলে পোর্ট খুলুন

AWS, Oracle Cloud, Google Cloud, Azure ইত্যাদিতে সার্ভারের বাইরে আরেকটা ফায়ারওয়াল থাকে। সেখানে এই পোর্টগুলো খুলতে হবে:

পোর্টপ্রোটোকলকেন লাগে
80TCPপ্যানেল (HTTP)
443TCPশুধু পরে ডোমেইন দিয়ে HTTPS চালু করলে লাগবে
6881-6999TCP + UDPটরেন্টের স্পিড ভালো পেতে
  • AWS: EC2 → Instance → Security → Security Group → Edit inbound rules
  • Oracle Cloud: Instance → Subnet → Security List → Add Ingress Rules (Oracle-এ সার্ভারের ভেতরের iptables-ও খুলতে হতে পারে, সমস্যা সমাধান দেখুন)
  • Google Cloud: VPC network → Firewall → Create firewall rule
ℹ️ পোর্ট খুলতে না পারলেDigitalOcean, Contabo, Vultr, Hetzner-এ সাধারণত কিছু করতে হয় না। আর পোর্ট খোলা একদম সম্ভব না হলে (যেমন বাসার পিসি) TUNNEL=1 দিয়ে ইনস্টল করুন, উপায় ৩ দেখুন।

৪ প্যানেলে লগইন

  1. ব্রাউজারে খুলুন: http://SERVER-IP/
  2. ইউজারনেম admin, আর ইনস্টলের শেষে পাওয়া পাসওয়ার্ড দিন → লগইন
  3. লগইন ৩০ দিন মনে থাকবে।
ℹ️ ব্রাউজার "Not secure" দেখাতে পারেডোমেইন ছাড়া HTTP-তে চালালে এটা স্বাভাবিক। প্যানেল ঠিকমতোই কাজ করবে।
⚠️ ৫ বার ভুল পাসওয়ার্ড দিলেওই ডিভাইস ১৫ মিনিটের জন্য ব্লক হয়ে যাবে। এটা হ্যাকারদের আটকানোর জন্য।

৫ Cloud কানেক্ট (ঐচ্ছিক, একবারই করতে হয়)

☁ Cloud ট্যাবে যান। প্রথমবার কানেক্ট করার বক্স দেখাবে। পরে আরেকটা একাউন্ট যোগ করতে ➕ নতুন একাউন্ট চাপুন।

Google Drive, Dropbox, OneDrive

ধরন বাছুন→🔑 লিংক তৈরি→লগইন করে Allow→খুলবে না এমন পেজ→লিংক কপি→✔ কানেক্ট
  1. কোন ধরনের? থেকে Google Drive, Dropbox বা OneDrive বাছুন।
  2. 🔑 লগইন লিংক তৈরি করো চাপুন। নতুন ট্যাবে লগইন পেজ খুলবে (না খুললে "লগইন পেজ খুলুন" লিংকে চাপুন)।
  3. একাউন্টে লগইন করে Allow দিন।
  4. এরপর একটা পেজ আসবে যেটা খুলবে না ("This site can't be reached", ঠিকানায় 127.0.0.1:53682 লেখা)। এটাই স্বাভাবিক।
  5. ওই পেজের address bar-এর পুরো লিংকটা কপি করুন। দেখতে এরকম: http://127.0.0.1:53682/?state=abc123&code=4/0AQl...
  6. প্যানেলে ফিরে বক্সে পেস্ট করুন → ✔ কানেক্ট।

Mega

কোন ধরনের? থেকে Mega বেছে শুধু ইমেইল আর পাসওয়ার্ড দিন। Mega-তে 2FA চালু থাকলে কাজ করবে না।

✅ হয়ে গেলেCloud-এর ফাইল তালিকা দেখাবে। একাধিক একাউন্ট থাকলে উপরের Cloud একাউন্ট লিস্ট থেকে বদলাবেন।
⚠️ মোবাইলে করলেকিছু মোবাইল ব্রাউজারে খুলবে না এমন পেজের ঠিকানা কপি করা কঠিন। সেক্ষেত্রে পিসি থেকে এই ধাপটা করুন।
বিকল্প পদ্ধতি: টোকেন দিয়ে কানেক্ট
  1. নিজের পিসিতে rclone নামান: rclone.org/downloads
  2. পিসির CMD/Terminal-এ চালান: rclone authorize "drive" (Dropbox হলে "dropbox", OneDrive হলে "onedrive")
  3. ব্রাউজারে লগইন করে Allow দিন।
  4. Terminal-এ ---> আর <---End paste-এর মাঝের লেখা কপি করুন।
  5. প্যানেলে বিকল্প: টোকেন দিয়ে কানেক্ট খুলে পেস্ট করুন → ✔ কানেক্ট।

⬇️ ডাউনলোড করা

  1. ⬇ ডাউনলোড ট্যাবের বড় বক্সে লিংক পেস্ট করুন। একসাথে অনেকগুলো দিতে চাইলে প্রতি লাইনে একটা।
  2. কোথায় / কীভাবে? বেছে নিন:
    • সার্ভারে: সবচেয়ে সাধারণ। YouTube/Facebook-এর লিংক হলে নিজে থেকেই ভিডিও হিসেবে নামবে।
    • ভিডিও সাইট হিসেবে: উপরের তালিকায় নেই এমন সাইটের ভিডিও (yt-dlp ১০০০+ সাইট চেনে)।
    • সরাসরি Cloud-এ: শুধু http/https লিংক, সার্ভারে জায়গা লাগবে না। কোন একাউন্টে যাবে সেটাও বাছুন।
  3. ভিডিও হলে কোয়ালিটি বাছুন: সবচেয়ে ভালো, 1080p, 720p, 480p (কম ডাটা), বা শুধু অডিও (MP3)। পুরো প্লেলিস্ট চাইলে টিক দিন। সাবটাইটেলসহ চাইলে সাবটাইটেল সহ টিক দিন আর ভাষা লিখুন (যেমন bn,en)। ভিডিওতে সাবটাইটেল না থাকলে YouTube-এর অটো-সাবটাইটেল আসবে।
  4. চাইলে ফোল্ডার-এর নাম দিন (যেমন Movies)।
  5. ⬇ ডাউনলোড শুরু চাপুন। .torrent ফাইল থাকলে 📄 .torrent ফাইল বাটন দিয়ে দিন।

🎞️ ভিডিওর সাবটাইটেল

ফাইল ট্যাবে ভিডিওর পাশে 🎞 বাটন চাপলে একটা window খুলবে।

সাবটাইটেল দুই রকমের

ধরনচেনার উপায়কী করা যায়
আলাদা (soft)প্লেয়ারে চালু/বন্ধ করা যায়, সাধারণত MKV/MP4-এ থাকেদেখা, মোছা, নতুন যোগ, .srt হিসেবে বের করা, সবই কয়েক সেকেন্ডে। কোয়ালিটি কমে না
ছবির ভেতরে বসানো (hard)কোনোভাবেই বন্ধ করা যায় না❌ মোছা যায় না। তবে নতুন সাবটাইটেল বসানো (burn-in) যায়

মুছে ফেলা বা নতুন যোগ করা (দ্রুত)

  1. উপরে ভিডিওর ভেতরের সব সাবটাইটেল দেখাবে (ভাষা, নাম, কোনটা ডিফল্ট)। যেটা বাদ দিতে চান তার পাশে মুছো টিক দিন।
  2. নতুন যোগ করতে ⬆ পিসি থেকে চেপে .srt / .ass / .vtt ফাইল দিন, অথবা ভিডিওর ফোল্ডারে আগে থেকে থাকা ফাইল বেছে ➕ যোগ চাপুন।
  3. প্রতিটা নতুন সাবটাইটেলের ভাষা ঠিক করুন (ফাইলের নামে bn/bangla/en থাকলে নিজে থেকে বসে যায়), চাইলে একটা নাম দিন।
  4. কোনটা ডিফল্ট হবে বাছুন। ডিফল্ট সাবটাইটেল প্লেয়ারে নিজে থেকে চালু হয়।
  5. 💾 সেভ চাপুন। "[subs]" নামে নতুন ফাইল তৈরি হবে। আসল ফাইল বদলে দাও টিক দিলে আসল ফাইলটাই বদলে যাবে।

সাবটাইটেল আলাদা ফাইল হিসেবে বের করা

ভেতরের কোনো সাবটাইটেলের পাশে ⬇ .srt চাপলে ভিডিওর পাশেই একটা .srt ফাইল তৈরি হবে। সেটা নামিয়ে এডিট বা অনুবাদ করে আবার যোগ করতে পারবেন।

🔥 ছবির ভেতরে বসানো (burn-in)

যেসব টিভি বা প্লেয়ারে সাবটাইটেল চালু করা যায় না, বা Facebook-এ আপলোডের জন্য। নিচের লিস্ট থেকে সাবটাইটেল বেছে 🔥 বসাও চাপুন। "[hardsub]" নামে নতুন MP4 তৈরি হবে।

⚠️ সময় লাগেপুরো ভিডিও নতুন করে বানাতে হয়। ছোট সার্ভারে ২ ঘণ্টার মুভিতে ১ ঘণ্টা বা তার বেশি লাগতে পারে। 🔄 ট্রান্সফার ট্যাবে progress আর বাকি সময় দেখা যায়, দরকার হলে বাতিল করা যায়।
ℹ️ বাংলা লেখাবাংলা সাবটাইটেল বসানোর জন্য দরকারি ফন্ট (Noto) ইনস্টলের সময় নিজে থেকে বসে যায়। .srt ফাইল UTF-8 এনকোডিংয়ে হতে হবে (বেশিরভাগ বাংলা সাবটাইটেল তাই থাকে)।

✈️ Telegram বট

এটা চালু করলে ডাউনলোড শেষ হলে ফোনে মেসেজ আসবে, আর প্যানেল না খুলেই বটকে লিংক পাঠিয়ে ডাউনলোড করা যাবে।

চালু করার নিয়ম (৫ মিনিট)

  1. Telegram-এ @BotFather খুঁজে খুলুন, /newbot পাঠান। বটের একটা নাম আর একটা ইউজারনেম (শেষে bot) দিন।
  2. BotFather একটা টোকেন দেবে (যেমন 123456:ABC-xyz...)। প্যানেলের ⚙ সেটিং → Telegram বট-এ বসিয়ে 💾 সেভ চাপুন।
  3. এবার Telegram-এ আপনার নতুন বট খুলে /start পাঠান। বট আপনার Chat ID বলে দেবে।
  4. সেই Chat ID প্যানেলে বসিয়ে আবার 💾 সেভ, তারপর 📨 পরীক্ষা চাপুন। বটের কাছ থেকে মেসেজ এলে কাজ শেষ।

📡 RSS অটো ডাউনলোড

অনেক টরেন্ট সাইট আর পডকাস্টের RSS লিংক থাকে। সেটা দিলে নতুন আইটেম এলেই নিজে থেকে নামবে, যেমন প্রতি সপ্তাহের নতুন পর্ব।

  1. 📡 RSS ট্যাবে RSS লিংক, একটা নাম আর চাইলে ফিল্টার দিন → ➕ যোগ করো।
  2. ফিল্টার: যে শব্দগুলো লিখবেন সবগুলো নামে থাকতে হবে। শব্দের আগে - দিলে সেই শব্দ থাকলে বাদ। যেমন my show 1080p -720p।
  3. প্রথমবার আগের সব আইটেম বাদ দেওয়া হয়, যাতে পুরনো সব একসাথে নামা শুরু না হয়। এরপর থেকে আসা নতুনগুলো নামবে।
  4. কোন ফোল্ডারে নামবে আর কত মিনিট পরপর চেক হবে (কমপক্ষে ৫) নিচে ঠিক করুন। 🔄 এখনই চেক করো দিয়ে সাথে সাথে চেক করা যায়।

⚙️ সেটিং ও ইউজার

🚀 স্পিড লিমিট

ডাউনলোড আর আপলোড (seeding) স্পিড KB/s-এ দিন। 0 মানে লিমিট নেই। যেমন ৫ MB/s চাইলে 5000।

⏰ নির্দিষ্ট সময়ে ডাউনলোড

টিক দিয়ে শুরু আর শেষের সময় দিন (যেমন রাত ১টা থেকে সকাল ৮টা)। বাকি সময় সব ডাউনলোড থেমে থাকবে। রাতের ফ্রি ইন্টারনেট প্যাকেজের জন্য কাজে লাগে। সময় আপনার ফোন/পিসির সময় অনুযায়ী ধরা হয়।

💾 ডিস্ক রক্ষা

খালি জায়গা এর কম হলে (ডিফল্ট ২ GB) সব ডাউনলোড নিজে থেকে থেমে যাবে, যাতে সার্ভার আটকে না যায়। প্যানেলের উপরে লাল সতর্কবার্তা দেখাবে, Telegram-এও মেসেজ যাবে। কিছু ফাইল মুছে ▶ সব চালাও চাপুন।

🤖 অটো আপলোড

  1. সার্ভারে ডাউনলোড শেষ হলেই Cloud-এ পাঠাও টিক দিন।
  2. কোন Cloud একাউন্টে আর কোন ফোল্ডারে যাবে বাছুন (ডিফল্ট aria2)।
  3. সার্ভারে জায়গা কম হলে আপলোডের পর সার্ভার থেকে মুছে ফেলো টিক দিন → 💾 সেভ।

🔒 HTTPS (ঐচ্ছিক, এখন বাদ দিতে পারেন)

ডোমেইন ছাড়া প্যানেল http://SERVER-IP/ ঠিকানায় চলে, সব ফিচার কাজ করে। পরে ডোমেইন নিলে নিচের ধাপগুলো করলেই HTTPS চালু হবে।

HTTPS কেন?

  • লগইনের পাসওয়ার্ড আর ফাইল এনক্রিপ্ট হয়ে যায়। পাবলিক WiFi থেকেও নিরাপদ থাকে।
  • ব্রাউজারে "Not secure" লেখা চলে যায়।
  • IP-র বদলে মনে রাখার মতো ঠিকানা পান, যেমন https://dl.example.com।

যা লাগবে

জিনিসকোথায় পাবেনখরচ
একটা ডোমেইনNamecheap, Porkbun, Cloudflare, GoDaddy, বা বাংলাদেশি রেজিস্ট্রারবছরে প্রায় ১০০০ থেকে ১৫০০ টাকা (.com)
একটা ইমেইলআপনার Gmail-ই চলবেফ্রি

ℹ️ ডোমেইন কিনতে না চাইলেsslip.io (উপায় ২) বা Cloudflare Tunnel (উপায় ৩) দিয়ে ফ্রিতে HTTPS করা যায়।

উপায় ১: নিজের ডোমেইন দিয়ে

A record দিন→DNS চেক→পোর্ট 80/443 খুলুন→একটা কমান্ড→🔒 https://

ধাপ ১: DNS-এ A record যোগ করুন। ডোমেইন যেখান থেকে কিনেছেন, সেখানকার DNS সেটিংয়ে:

TypeName / HostValue / Points toTTL
Adl (ঠিকানা হবে dl.example.com), অথবা @ (শুধু example.com)আপনার সার্ভারের IPAuto

ধাপ ২: DNS কাজ করছে কিনা দেখুন। ৫ মিনিট থেকে কয়েক ঘণ্টা লাগতে পারে:

ping dl.example.com

উত্তরে আপনার সার্ভারের IP দেখালে পরের ধাপে যান।

ধাপ ৩: পোর্ট খুলুন। AWS, Oracle বা Google Cloud হলে ওদের প্যানেলে 80 আর 443 TCP খোলা আছে কিনা দেখুন। Let's Encrypt পোর্ট 80 দিয়ে যাচাই করে।

ধাপ ৪: এই একটা কমান্ড চালান (dl.example.com আর ইমেইল বদলে নিজেরগুলো দিন):

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo DOMAIN=dl.example.com EMAIL=you@gmail.com bash

script নিজে থেকে ফ্রি সার্টিফিকেট নেয়, HTTPS চালু করে, http:// দিয়ে কেউ ঢুকলে https://-এ পাঠিয়ে দেয়, আর ডোমেইনটা মনে রাখে।

ধাপ ৫: খুলুন https://dl.example.com/। পাসওয়ার্ড, ফাইল আর Drive কানেকশন আগের মতোই থাকবে।

⚠️ মনে রাখবেনHTTPS চালু হওয়ার পর http://SERVER-IP/ দিয়ে আর ঢোকা যাবে না, শুধু ডোমেইন দিয়ে খুলবে।

উপায় ২: ডোমেইন না কিনে, ফ্রি (sslip.io)

DNS-এ কিছু করতে হয় না। IP-র ডট (.) বদলে ড্যাশ (-) দিন। যেমন IP 203.0.113.10 হলে:

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo DOMAIN=203-0-113-10.sslip.io EMAIL=you@gmail.com bash

প্যানেল খুলবে https://203-0-113-10.sslip.io/ ঠিকানায়। ঠিকানাটা মনে রাখা একটু কঠিন, কিন্তু পুরোপুরি ফ্রি। কখনো সার্টিফিকেট পেতে দেরি হলে কিছুক্ষণ পরে আবার চালান।

উপায় ৩: Cloudflare Tunnel (ডোমেইন বা পোর্ট খোলা ছাড়াই)

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo TUNNEL=1 bash

একটা https://xxxx.trycloudflare.com লিংক পাবেন। কোনো পোর্ট খুলতে হয় না, তাই বাসার পিসি বা কড়া ফায়ারওয়ালের সার্ভারেও চলে।

  • ⚠️ সার্ভার বা Tunnel রিস্টার্ট হলে লিংক বদলে যায়। নতুন লিংক দেখতে: sudo aria2-panel url, বা প্যানেলের ⚙ সেটিং-এ দেখুন। Telegram বট চালু থাকলে নতুন লিংক নিজে থেকেই মেসেজে আসবে।
  • Tunnel দিয়ে একবারে প্রায় ১০০ MB-র বেশি আপলোড আটকে যেতে পারে। বড় ফাইল আপলোডের জন্য IP দিয়ে খুলুন।
  • বন্ধ করতে: ... | sudo TUNNEL=0 bash

Cloudflare ব্যবহার করলে

  • DNS record-এর Proxy status প্রথমে DNS only (ধূসর মেঘ) রাখুন, তারপর script চালান।
  • সার্টিফিকেট পাওয়ার পর চাইলে Proxied (কমলা মেঘ) করতে পারেন। তখন Cloudflare-এর SSL/TLS → Overview থেকে Full (strict) করে দিন।
  • ⚠️ Proxied অবস্থায় Cloudflare ফ্রি প্ল্যানে একবারে প্রায় ১০০ MB-র বেশি আপলোড করতে দেয় না। বড় ফাইল আপলোড করলে DNS only রাখাই ভালো।

"certbot failed" দেখালে কী করব?

প্যানেল HTTP-তেই চলতে থাকবে, কিছু নষ্ট হবে না। এগুলো দেখে একই কমান্ড আবার চালান:

  1. DNS এখনো ছড়ায়নি: ping dl.example.com চালিয়ে দেখুন আপনার সার্ভারের IP দেখায় কিনা।
  2. পোর্ট 80 বন্ধ: ক্লাউড প্যানেলের ফায়ারওয়াল দেখুন। Oracle হলে iptables-ও (সমস্যা সমাধান দেখুন)।
  3. Cloudflare Proxied চালু: DNS only করে আবার চালান।
  4. অনেকবার চেষ্টা করেছেন: Let's Encrypt ঘণ্টায় ৫ বারের বেশি ব্যর্থ চেষ্টা করতে দেয় না। এক ঘণ্টা অপেক্ষা করুন।

বিস্তারিত এরর: sudo tail -n 50 /var/log/letsencrypt/letsencrypt.log

❓ প্রশ্নোত্তর

সার্ভার রিস্টার্ট দিলে কি ডাউনলোড হারিয়ে যাবে?

না। aria2 প্রতি ৩০ সেকেন্ডে অবস্থা সেভ করে, রিস্টার্টের পর যেখানে থেমেছিল সেখান থেকে আবার চলবে। প্যানেলও নিজে থেকে চালু হয়। (চলমান ভিডিও বা Cloud ট্রান্সফার আবার দিতে হবে।)

একসাথে কয়টা ডাউনলোড চলবে?

৫টা একসাথে চলে, বাকিগুলো অপেক্ষায় থাকে। বদলাতে চাইলে /etc/aria2/aria2.conf-এ max-concurrent-downloads বদলে sudo aria2-panel restart দিন।

অন্য কাউকে ফাইল দিতে চাই, কিন্তু পাসওয়ার্ড দিতে চাই না

ফাইল বা ফোল্ডারের পাশে 🔗 চাপুন। যে লিংক কপি হবে সেটা দিয়ে লগইন ছাড়াই নামানো যাবে। অথবা তাকে viewer ইউজার বানিয়ে দিন।

মোবাইল থেকে চালানো যাবে?

হ্যাঁ। প্যানেল মোবাইলের জন্য বানানো, আর ফোনের সেটিং অনুযায়ী dark mode নিজে থেকে চালু হয়। আরো সহজে চাইলে Telegram বট ব্যবহার করুন।

এটা কি নিরাপদ?

প্যানেলে পাসওয়ার্ড ছাড়া ঢোকা যায় না, বারবার ভুল পাসওয়ার্ড দিলে ব্লক হয়, আর aria2 বাইরে থেকে সরাসরি খোলা থাকে না। সার্ভারের সিকিউরিটি আপডেটও নিজে থেকে হয়। শক্ত পাসওয়ার্ড রাখুন, আর চাইলে HTTPS চালু করুন (ডোমেইন ছাড়াও করা যায়, এখানে দেখুন)।

ইউটিউব থেকে নামানো কি বৈধ?

নিজের ভিডিও, ফ্রি লাইসেন্সের ভিডিও বা ব্যক্তিগত ব্যবহারের জন্য অনুমতি আছে এমন কনটেন্ট নামান। অন্যের কপিরাইট করা কনটেন্ট নামানো বা ছড়ানো আপনার দেশের আইন আর সাইটের নিয়ম অনুযায়ী অবৈধ হতে পারে।
