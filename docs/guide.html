৩ ক্লাউড প্যানেলে পোর্ট খুলুন

AWS, Oracle Cloud, Google Cloud, Azure ইত্যাদিতে সার্ভারের বাইরে আরেকটা ফায়ারওয়াল থাকে। সেখানে এই পোর্টগুলো খুলতে হবে, না হলে প্যানেল খুলবে না:

পোর্টপ্রোটোকলকেন লাগে
80TCPপ্যানেল (HTTP)
443TCPশুধু পরে HTTPS চালু করলে লাগবে
6881-6999TCP + UDPটরেন্টের স্পিড ভালো পেতে
  • AWS: EC2 → Instance → Security → Security Group → Edit inbound rules
  • Oracle Cloud: Instance → Subnet → Security List → Add Ingress Rules (Oracle-এ সার্ভারের ভেতরের iptables-ও খুলতে হতে পারে, নিচে সমস্যা সমাধান দেখুন)
  • Google Cloud: VPC network → Firewall → Create firewall rule
ℹ️ সাধারণ VPSDigitalOcean, Contabo, Vultr, Hetzner ইত্যাদিতে সাধারণত আলাদা কিছু করতে হয় না।

৫ Google Drive কানেক্ট (একবারই করতে হয়)

🔑 লিংক তৈরি→Google-এ Allow→খুলবে না এমন পেজ→লিংক কপি→✔ কানেক্ট
  1. প্যানেলের ☁ Google Drive ট্যাবে যান।
  2. 🔑 Google লগইন লিংক তৈরি করো বাটনে চাপ দিন। নতুন ট্যাবে Google-এর পেজ খুলবে (না খুললে নিচের "Google লগইন পেজ খুলুন" লিংকে চাপুন)।
  3. আপনার Google একাউন্ট বেছে নিন, তারপর Allow দিন।
  4. এরপর একটা পেজ আসবে যেটা খুলবে না ("This site can't be reached", ঠিকানায় 127.0.0.1:53682 লেখা)। এটাই স্বাভাবিক, ভয় পাবেন না।
  5. ওই পেজের address bar-এ থাকা পুরো লিংকটা কপি করুন। দেখতে এরকম:
    http://127.0.0.1:53682/?state=abc123&code=4/0AQl...
  6. প্যানেলের ট্যাবে ফিরে বক্সে পেস্ট করুন → ✔ কানেক্ট।
✅ হয়ে গেলেDrive-এর ফাইল তালিকা দেখাবে, আর উপরে কত জায়গা ব্যবহার হয়েছে দেখাবে।
⚠️ মোবাইলে করলেকিছু মোবাইল ব্রাউজারে খুলবে না এমন পেজের ঠিকানা কপি করা কঠিন। সেক্ষেত্রে পিসি থেকে এই ধাপটা করুন। একবার কানেক্ট করলেই সব ডিভাইসে কাজ করবে।
বিকল্প পদ্ধতি: টোকেন দিয়ে কানেক্ট

উপরের পদ্ধতি কাজ না করলে:

  1. নিজের পিসিতে rclone নামান: rclone.org/downloads
  2. পিসির CMD/Terminal-এ চালান: rclone authorize "drive"
  3. ব্রাউজারে Google লগইন করে Allow দিন।

  5. প্যানেলে টোকেন পদ্ধতি ট্যাবে পেস্ট করে ✔ কানেক্ট চাপুন।

🔐 পাসওয়ার্ড বদলানো

সেটিং ট্যাবে বর্তমান আর নতুন পাসওয়ার্ড (৮ অক্ষর বা বেশি) দিয়ে বদলাও চাপুন।

পাসওয়ার্ড ভুলে গেলে?

সার্ভারে এই কমান্ড চালান। আপনার ফাইল বা সেটিং কিছুই মুছবে না, শুধু পাসওয়ার্ড বদলাবে:

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo PANEL_PASSWORD='NewPass12345' bash

🔒 HTTPS (ঐচ্ছিক, এখন বাদ দিতে পারেন)

ডোমেইন ছাড়া প্যানেল http://SERVER-IP/ ঠিকানায় চলে, সব ফিচার কাজ করে। শুধু পাসওয়ার্ড এনক্রিপ্ট হয় না, তাই পাবলিক WiFi থেকে লগইন না করাই ভালো। পরে HTTPS চাইলে নিচের যেকোনো একটা উপায়:

উপায় ১: ফ্রি নাম (sslip.io), ডোমেইন কেনা লাগবে না

সার্ভারের IP-র ডট (.) বদলে ড্যাশ (-) দিয়ে নাম হবে, যেমন IP 203.0.113.10 হলে 203-0-113-10.sslip.io:

curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo DOMAIN=203-0-113-10.sslip.io EMAIL=you@gmail.com bash

উপায় ২: নিজের ডোমেইন থাকলে

  1. ডোমেইনের DNS প্যানেলে একটা A record বানান: নাম @ বা dl, মান আপনার সার্ভারের IP।
  2. কয়েক মিনিট অপেক্ষা করুন, তারপর চালান:
curl -fsSL https://raw.githubusercontent.com/ABNET-RAKIB-123/aria2/main/install.sh | sudo DOMAIN=dl.example.com EMAIL=you@gmail.com bash

এরপর প্যানেল খুলবে https://dl.example.com/ ঠিকানায়। সার্টিফিকেট ফ্রি, আর নিজে থেকেই রিনিউ হয়।

ℹ️ আগে থেকে ইনস্টল করা থাকলেএকই কমান্ড আবার চালালেই হবে। ফাইল, পাসওয়ার্ড আর Drive কানেকশন থেকে যাবে।
  • ডোমেইনটা মনে থাকে। পরে আপডেটের সময় শুধু সাধারণ ইনস্টল কমান্ড চালালেই HTTPS থেকে যাবে।
  • HTTPS চালু হওয়ার পর http://SERVER-IP/ দিয়ে আর ঢোকা যাবে না, শুধু ডোমেইন দিয়ে খুলবে।
  • আবার IP-তে ফিরে যেতে চাইলে: ... | sudo DOMAIN=none bash
  • Cloudflare ব্যবহার করলে প্রথমে DNS record DNS only (ধূসর মেঘ) রাখুন।
  • DNS record, Cloudflare, সমস্যা সমাধানসহ পুরো নিয়ম README-র "HTTPS (ঐচ্ছিক)" অংশে আছে।

🩺 সমস্যা সমাধান

ব্রাউজারে প্যানেল খুলছে না
  1. সার্ভিস চলছে কিনা দেখুন: sudo systemctl status aria2-panel nginx (active (running) দেখাতে হবে)
  2. সার্ভারের ভেতর থেকে চেক করুন: curl -I http://127.0.0.1/
  3. এটা কাজ করলে সমস্যা ফায়ারওয়ালে। ৩ নম্বর ধাপ দেখুন।
  4. Oracle Cloud হলে সার্ভারের ভেতরের iptables-ও খুলতে হয়: 
    sudo iptables -I INPUT 6 -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
ডাউনলোড তালিকায় "aria2 is not running" দেখাচ্ছে 
sudo systemctl restart aria2
sudo journalctl -u aria2 -n 50

লগে এরর দেখলে সেটা কপি করে রাখুন।

টরেন্ট শুরু হচ্ছে না বা খুব ধীরে চলছে
  • ক্লাউড ফায়ারওয়ালে 6881-6999 TCP+UDP খোলা আছে কিনা দেখুন।
  • tracker তালিকা নিজে আপডেট করুন: sudo /usr/local/bin/aria2-update-trackers
  • অনেক টরেন্টে seeder কম থাকে, তখন স্পিড কম হবেই।
Google Drive কানেক্ট হচ্ছে না
  • address bar-এর পুরো লিংক কপি করেছেন কিনা দেখুন, তাতে code= থাকতে হবে।
  • লিংক তৈরির পর বেশি দেরি করলে মেয়াদ চলে যায়। আবার 🔑 Google লগইন লিংক তৈরি করো চাপুন।
  • তাও না হলে বিকল্প টোকেন পদ্ধতি ব্যবহার করুন (৫ নম্বর ধাপ)।

  • ইন্টারনেট কানেকশন স্থির আছে কিনা দেখুন। আপলোড চলার সময় পেজ বন্ধ বা রিফ্রেশ করবেন না।

❓ প্রশ্নোত্তর

সার্ভার রিস্টার্ট দিলে কি ডাউনলোড হারিয়ে যাবে?

না। aria2 প্রতি ৩০ সেকেন্ডে অবস্থা সেভ করে, রিস্টার্টের পর যেখানে থেমেছিল সেখান থেকে আবার চলবে। প্যানেলও নিজে থেকে চালু হয়।

একসাথে কয়টা ডাউনলোড চলবে?

৫টা একসাথে চলে, বাকিগুলো অপেক্ষায় থাকে। বদলাতে চাইলে /etc/aria2/aria2.conf-এ max-concurrent-downloads বদলে sudo systemctl restart aria2 দিন।

অন্য কাউকে ফাইল দিতে চাই, কিন্তু পাসওয়ার্ড দিতে চাই না

ফাইলের পাশে 🔗 চাপুন। যে লিংক কপি হবে সেটা ৭ দিন চলবে, লগইন লাগবে না।

মোবাইল থেকে চালানো যাবে?

হ্যাঁ। প্যানেল মোবাইলের জন্য বানানো, আর ফোনের সেটিং অনুযায়ী dark mode নিজে থেকে চালু হয়।

এটা কি নিরাপদ?

প্যানেলে পাসওয়ার্ড ছাড়া ঢোকা যায় না, আর aria2 বাইরে থেকে সরাসরি খোলা থাকে না। শক্ত পাসওয়ার্ড রাখুন, আর চাইলে পরে HTTPS চালু করুন (ডোমেইন ছাড়াও করা যায়, এখানে দেখুন), তাহলে পাসওয়ার্ড এনক্রিপ্ট হয়ে যাবে।
